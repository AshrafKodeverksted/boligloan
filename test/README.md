# Boliglån - Mortgage Tracker

A personal mortgage tracking application designed to help users monitor their outstanding loan balance, payments, interest and principal repayments.

## Current Features

- Display the outstanding loan balance
- Register payments
- Validate payment amounts
- Update the displayed balance

## Technologies

- HTML
- CSS
- JavaScript

## Planned Improvements

- Rebuild the frontend with React
- Add a Java and Spring Boot backend
- Store loan and payment data in PostgreSQL
- Track interest (renter) and principal repayments (avdrag) separately
- Add payment history and contribution tracking

## Project Status

This project is under active development and is also a learning project for practicing software development, version control and application architecture.
